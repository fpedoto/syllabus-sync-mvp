# Five-Minute Test Script

## Before each session

Confirm that the participant is an undergraduate currently managing at least four courses. Assign the next anonymous ID in `EVIDENCE.md`. Start with a fresh private/incognito window. Do not ask for a name, email, or course information.

## Read exactly

“We are testing the product, not you. Please use sample or non-sensitive syllabus text. Try to create a calendar file without help. You may stop at any time. We will record only anonymous completion steps, elapsed time, and visible friction—no names or syllabus content. Begin when you are ready.”

Start the five-minute timer when the participant begins. Do not explain the interface. If asked for help, say, “Please do what you would normally do,” and mark the session assisted if you provide any additional direction.

## Record behavior

Record whether the participant opened the site, began pasting, reached review, downloaded within five minutes, needed help, clicked the offer, and opened the calendar file. Record the first visible friction, not a guess about what the participant felt.

After the attempt, ask only:

1. “What did you expect to happen at the point where you first hesitated?”
2. “What would you normally use instead?”

Run 10 participants as Wave 1. Make one consequential, evidence-supported revision and record it in `REVISION_RECEIPT.md`. Then run 10 new eligible participants as Wave 2 under the same script.
